# Topic 01 Estimation — 知識點（範例檔，可刪除或改寫）

## Significant figures
- Non-zero digits are always significant; zeros between non-zero digits are significant.
- Leading zeros are not significant, e.g. 0.00304 has 3 significant figures.
- Trailing zeros in a decimal are significant, e.g. 2.500 has 4 significant figures.

## Scientific notation
- A number written as $a \times 10^n$ where $1 \le a < 10$ and $n$ is an integer.

## Errors in measurement
- Maximum absolute error $= \frac{1}{2} \times$ scale interval.
- Relative error $= \dfrac{\text{maximum absolute error}}{\text{measured value}}$.
- Percentage error $=$ relative error $\times 100\%$.
- Lower limit $=$ measured value $-$ maximum absolute error; upper limit $=$ measured value $+$ maximum absolute error.

## Estimation strategies
- Rounding off, rounding up, rounding down; front-end estimation.
- Decide whether an estimate is an over-estimate or under-estimate in context (e.g. budget questions should round prices up).
